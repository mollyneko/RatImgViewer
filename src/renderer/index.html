默认看图软件

按 Windows 规定，程序不能自己把自己设成默认打开方式（微软刻意禁止，防止软件抢关联）。 正确做法是：本程序先把自己注册成候选，再由你在系统设置里点一下确认。 下面一键完成前两步。

1
点「① 注册为候选看图程序」——写入 HKCU 注册表（无需管理员权限，只写当前用户）。
2
点「② 打开系统默认应用页」——在 Windows 11 会直接跳到本程序的页面。
3
把 .jpg .png .webp .cdr .psd 等扩展名逐个选成 Rat看图王，完成。
